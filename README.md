# Соевая лавка

Макет продуктового сайта для двух фасовок тофу. Посетитель может сравнить упаковки, посмотреть точки продаж и ближайшие поставки. Для магазинов и кафе выделено предложение по опту.

[Открыть демо](https://sergo-proggger.github.io/tofu/)

Страница рассчитана на просмотр с компьютера и телефона. Основная реализация находится в [index.html](index.html), локальные зависимости — в [vendor](vendor/). Для просмотра скачайте репозиторий и откройте index.html в браузере.
